# Maddie Journey V4.3.7 — Living Office Experience

## Delivered

This release upgrades the existing interactive WebGL Virtual Office **without** changing any fictional employee records, dashboard calculations, division navigation, permission model or page routes.

### Natural scene behavior

- Deterministic illustrative 80-second activity loops: desk work, short aisle walks, group conversations, collaborative meetings and coffee breaks
- Eased journeys from desks to activity positions and back, bounded within each existing office room
- Staggered motion to avoid all people moving together; synchronized pairs for two-person conversations
- More expressive work, conversation, presentation, walking and coffee gestures
- Identical action poses for the instanced 3D floor overview and the detailed division camera
- Coffee cup visibility and sipping gesture only during the coffee activity
- Subtle per-person contact shadows plus soft architectural light accents and meeting-area rugs

### Control and accessibility

- **Office settings → Illustrative activity** toggles animation, persisted locally as `mc.officeLifeMotion`
- `prefers-reduced-motion` and the existing reduced-motion class automatically suppress character animation
- The existing low-cost, auto, balanced and quality graphics settings remain intact; no extra shadow lights or dynamic shadow maps
- Existing WebGL failure fallback, map directory, selection behavior, headcount labels and all read-only monitoring paths are preserved
- Activities are deliberately **fictional visualizations**, not live presence, productivity or employee behavior data

### Technical files

- `maddie-office-life.js`: no-network deterministic activity state function
- `p-hub.js`: shared overview/focus activity updates, animation setting, batched contact shadows
- `maddie-office-furnishings.js`: shared static decorative lighting and rugs
- `index.html` and `demo.html`: versioned script loading
- `tests/v437-living-office-contract.js`: deterministic movement, bounds, accessibility and boot order checks
- `tests/v436-office-interiors-contract.js`: updated script-cache contract

### Verification

Run both commands from the repository root:

```sh
node tests/v436-office-interiors-contract.js
node tests/v437-living-office-contract.js
```

Manual device validation remains necessary for GPU rendering, screen reader behavior, actual mobile frame rates, camera gesture smoothness and CSS WebGL fallback. Preserve a clear distinction between deterministic source-level verification and browser-based visual verification.
