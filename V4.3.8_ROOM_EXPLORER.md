# Maddie Journey V4.3.8 — Interactive Room Exploration

## Summary

Adds an unobtrusive, accessible room-inspection panel to the existing 3D Office. Direct changes on `main` only; no additional sample employees, authentication, backend, network integrations or route changes.

### Features

- Click a room to enter the same original interactive Three.js space.
- A **collapsible room inspector** displays the division's employee count, furnished-room description and existing fictional team records.
- Camera controls: **Room / Top / Front** presets and **Inspect avatar** for selected employees visible in a division.
- Room transitions temporarily retain architectural context for a short cinematic camera move (disabled with reduced motion).
- Select an employee from the compact list or a 3D avatar to highlight that person, preview existing 201-file and lateness statistics, and center the camera on the figure.
- **Full profile** opens the existing read-only employee profile modal. **Open division dashboard** uses the existing dashboard handler.
- Progressive disclosure: four people shown initially; the full team list is optional. Inspector collapsed by default on mobile to preserve scene visibility.
- Improved keyboard controls: `1` room camera, `2` top camera, `3` front camera, `i` toggles inspector, `0` resets camera.
- Consistent light/dark mode, semantic region/control labels, keyboard focus visibility, reduced-motion behavior and fallback room information.

### Implementation

- `p-hub.js`: room summaries, inspector rendering, camera targeting, transitions, employee selection.
- `maddie-office-explorer.css`: premium floating panel and responsive, accessible states.
- `index.html`, `demo.html`: versioned stylesheet and JavaScript references.
- `tests/v438-room-explorer-contract.js`: syntactic, behavior-contract, mock-record and control checks.
